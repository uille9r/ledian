# ledian 首版开发任务 01–02

## 01 · 初始化与局域网部署

在独立分支初始化应用和持久化存储，提供 Windows 启动方式。同一局域网中的成员通过浏览器访问运行服务的电脑。服务电脑在上班时运行，关机或休眠期间服务暂停。

在路由器上为运行 `ledian` 的 Windows 电脑设置 DHCP 地址保留。选择该局域网内可用的地址，例如 `192.168.1.50`，团队统一收藏服务网址，例如 `http://192.168.1.50:3000`。路由器按网卡地址保留 IP 时，服务电脑优先用网线，使用 Wi-Fi 时关闭该网络的随机硬件地址。成员设备继续使用 DHCP 自动获取地址。

验收：同网的另一台设备能打开登录页。服务电脑重连后取得同一 IP，成员笔记本断网重连后仍能用原书签访问。重启应用后，已保存的数据仍可读取。

## 02 · 团队邀请码注册与密码登录

成员首次访问时输入团队邀请码，自行设置账号和密码。后续使用个人账号和密码登录。邀请码仅在注册时使用。密码以哈希形式存储，邀请码通过部署配置提供。

验收：两名成员使用同一有效邀请码分别注册并登录。无效邀请码无法注册，错误密码无法登录。后续「推」按账号去重，站内未读状态按账号独立保存。
